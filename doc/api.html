REST API проекта

Все запросы выполняются по префиксу /api/ и возвращают JSON.

---

🔐 Auth

POST /api/auth/register/
POST /api/auth/login/
GET  /api/auth/verify-email/{uid}/{token}/

Пример ответа:
{
  "access_token": "jwt_token",
  "refresh_token": "refresh_token"
}
---

👤 Users

GET    /api/users/me/
GET    /api/users/{id}/
DELETE /api/users/{id}/
---

📍 Stories

GET    /api/stories/
POST   /api/stories/
GET    /api/stories/{id}/
DELETE /api/stories/{id}/
GET    /api/stories/my/
---

💬 Reviews

POST   /api/stories/{id}/reviews/
GET    /api/stories/{id}/reviews/
DELETE /api/reviews/{id}/
---

🛠 Admin

POST /api/admin/stories/{id}/publish/
POST /api/admin/stories/{id}/reject/
