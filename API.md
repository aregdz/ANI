# API и маршруты проекта

Проект «А.Н.И — Живая Карта Истории» реализован на базе Django и использует серверно-ориентированную архитектуру (server-rendered application). Взаимодействие пользователя с системой осуществляется через набор HTTP-маршрутов, которые обрабатывают основные функции: регистрацию и аутентификацию пользователей, управление историями, работу с отзывами, а также административные операции.

Маршруты принимают HTTP-запросы (GET/POST), обрабатывают их на стороне backend и возвращают HTML-страницы с необходимыми данными.

## Основные маршруты приложения

| Метод | Маршрут | Назначение |
|------|---------|-------------|
| GET | `/` | Главная страница с интерактивной картой и опубликованными историями |
| GET / POST | `/register/` | Регистрация нового пользователя |
| GET | `/verify-email/<uidb64>/<token>/` | Подтверждение email-адреса пользователя |
| GET / POST | `/login/` | Аутентификация пользователя |
| GET | `/logout/` | Завершение пользовательской сессии |
| GET / POST | `/password-reset/` | Инициация восстановления пароля |
| GET | `/password-reset/done/` | Подтверждение отправки письма для восстановления |
| GET / POST | `/reset/<uidb64>/<token>/` | Установка нового пароля |
| GET | `/reset/done/` | Подтверждение успешного изменения пароля |
| GET / POST | `/stories/add/` | Создание новой истории |
| GET | `/stories/my/` | Просмотр историй текущего пользователя |
| GET / POST | `/stories/<id>/` | Просмотр подробностей истории и добавление отзыва |
| GET | `/admin-panel/` | Панель администратора |
| GET / POST | `/admin-panel/stories/<id>/edit/` | Редактирование истории администратором |
| GET | `/admin-panel/stories/<id>/publish/` | Публикация истории |
| GET | `/admin-panel/stories/<id>/delete/` | Удаление истории |
| GET | `/admin-panel/users/<id>/delete/` | Удаление пользователя |
| GET | `/admin-panel/users/<id>/stories/` | Просмотр историй конкретного пользователя |
| GET | `/admin-panel/stories/<id>/reviews/` | Просмотр отзывов к истории |
| GET | `/admin-panel/reviews/<id>/delete/` | Удаление отзыва |

## Примечание

В текущей версии проекта не реализован отдельный REST API. Все взаимодействие происходит через серверные Django-маршруты, которые формируют и возвращают HTML-страницы. Таким образом, маршруты выполняют роль прикладного интерфейса между пользовательским интерфейсом и backend-логикой приложения.
