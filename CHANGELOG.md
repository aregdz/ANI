# История изменений

Все значимые изменения проекта фиксируются в данном файле.

Проект использует семантическое версионирование SemVer в формате `MAJOR.MINOR.PATCH`.

## [1.0.0] - 2026-05-24

### Добавлено

- Базовое отображение опубликованных историй.
- Интерактивная карта с отметками историй.
- Просмотр подробной информации об истории.
- Фильтрация историй по датам.
